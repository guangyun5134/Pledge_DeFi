# Pledge DeFi 抵押借贷平台

一个基于 EVM 的固定期限抵押借贷项目，包含借贷合约、用户前端和后台数据服务。

## 项目特点

- 通过借贷池组织借款人与出借人的资金，配置抵押资产和借贷期限。
- 使用凭证代币记录参与份额，支持存入、借款、赎回和到期结算。
- 包含价格预言机、抵押率检查及清算相关逻辑。
- Go 后端提供业务 API、数据库存储和定时链上同步。
- 前端展示借贷池、账户份额和借贷操作入口。

## 技术与目录

- `pledgev2/`：Solidity、Hardhat、OpenZeppelin、Chainlink 合约。
- `pledge-fe/`：React、Webpack、Web3 钱包交互前端。
- `pledge-backend/`：Go、Gin、GORM、MySQL、Redis 后端。
